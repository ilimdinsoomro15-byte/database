📚 Online Examination System
Project Overview
A comprehensive Java-based Online Examination System with separate interfaces for Administrators and Users. The system allows admins to create subjects, manage questions, and view results, while users can take exams and track their performance.

Features
👑 Admin Features
Dashboard: View system statistics (total subjects, questions, users, exams taken)

Subject Management: Create new subjects with custom duration

Question Management: Add/Manage questions for each subject

User Management: View all registered users

Result Monitoring: View all exam results across all users

👤 User Features
Available Exams: View all available subjects and their details

Exam Taking:

One-time attempt per subject

Timer-based examination

Question navigation (Previous/Next)

Real-time score preview

Auto-submit on timeout

Results History: View all past exam attempts with scores and grades

Profile Management: View personal information

Technology Stack
Frontend
Java Swing: GUI framework

Custom Components: Styled buttons, panels, and dialogs

Dark Theme: Modern dark interface design

Backend
Java JDBC: Database connectivity

MySQL: Relational database management system
